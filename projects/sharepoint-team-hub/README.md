# SharePoint Team Hub

A SharePoint intranet concept for organizing documents, announcements, quick links, and team resources.

## Features
- Team announcements
- Quick links
- Document library navigation
- Project/resource cards
- SharePoint-friendly information architecture

## Suggested Stack
SharePoint Online • Microsoft 365 • SPFx • TypeScript

## Portfolio Value
Demonstrates intranet planning, Microsoft 365 ecosystem knowledge, information architecture, and user-focused SharePoint customization.
